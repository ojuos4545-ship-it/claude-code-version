1. 에디터 **제목 칸**에 제목을 입력합니다.
2. `paste.html`을 열어 [본문 복사] → 에디터 본문에 붙여넣습니다.
3. 본문의 `【사진 NN】` 자리마다 아래 파일을 올리고, 표시 줄은 지웁니다.
4. 사진마다 대체 텍스트(ALT)를 넣습니다. 첫 사진(01)은 대표 사진으로 지정합니다.
