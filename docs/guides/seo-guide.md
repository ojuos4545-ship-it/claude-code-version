# 네이버 블로그 SEO 가이드 (seo-guide.md)

> 기준 시점: **2026년 10월**
> 이 문서는 블로그 작성 에이전트가 **네이버 검색 + AI 브리핑 노출**을 목표로 글을 쓸 때 반드시 참고하는 규칙집이다.
> 규칙의 우선순위: **[필수] > [권장] > [선택]**
> ⚠️ 네이버는 세부 수치(글자 수, 이미지 수, 키워드 횟수)를 공식 발표한 적이 없다. 이 문서의 수치는 업계 분석·실험값을 종합한 **안전 범위**이며, 수치보다 "검색 의도 충족"이 항상 우선한다.

---

## 0. 한눈에 보는 핵심 규칙 (요약)

1. **검색 의도 1개에 답하는 글 1개**: 큰 키워드보다 구체적인 세부(롱테일) 키워드를 노린다.
2. **제목 앞쪽에 핵심 키워드 1회**: 반복 금지.
3. **첫 문단에 결론**: 두괄식. AI 브리핑이 첫 문단 답변을 가장 잘 가져간다.
4. **소제목 + 리스트 + 표로 구조화**: AI와 사람 모두 읽기 쉽게.
5. **직접 경험 + 원본 이미지 + 공식 출처**: 2026년 신뢰도 평가의 핵심 재료.
6. **한 주제에 꾸준히**: 블로그 단위 신뢰도(C-Rank)가 쌓여야 노출과 AI 인용이 늘어난다.
7. **키워드 반복·복붙·대량 발행·글 삭제 금지**.

## 1. 2026년 네이버 검색 환경 이해 [필수 배경지식]

에이전트는 아래 변화를 전제로 글을 설계한다.

| 변화 | 내용 | 글쓰기에 주는 의미 |
| :--- | :--- | :--- |
| **AI 브리핑 확대** | 검색 결과 맨 위에 AI 요약 답변 + 출처 링크 노출. 월 이용자 약 3,000만 명 수준 | "AI가 인용하기 좋은 글"이 새 목표 |
| **블로그가 AI 브리핑 최대 출처** | 2026년 8~9월 분석에서 AI 브리핑 출처의 약 46.5%가 네이버 블로그 | 블로그 글이 여전히 가장 유리한 위치 |
| **인용은 순위와 별개** | 상위 10위 밖 글도 AI 브리핑에 인용되는 사례가 절반 가까이 됨 | 신규·소형 블로그도 구조만 좋으면 기회 있음 |
| **통합 랭킹(신뢰도 중심)** | 블로그·카페·웹문서가 한 영역에서 경쟁, 출처 신뢰도가 순위 결정 | 공신력·전문성·경험 근거가 필수 |
| **스마트블록 중심 검색결과** | 검색 의도별로 묶음 노출. VIEW 탭 폐지, 연관검색어 종료(2026.4) | 세부 의도 키워드 공략이 유리 |
| **저품질 판별에 LLM 활용** | AI 자동생성 글, 광고 도배, 경험 없는 후기를 걸러내겠다고 네이버가 발표 | AI 티 나는 글·양산형 글은 위험 |
| **네이버 메이트** | 조회수가 아닌 AI 브리핑 인용 수 기준으로 창작자 보상 | 인용 구조 최적화의 동기 |

> 📌 업계에서 쓰는 'AuthGR', 'QUMA' 같은 용어는 네이버 공식 발표로 확인되지 않은 표현이다. 공식 확인된 평가 축은 **C-Rank, D.I.A+, AI 브리핑** 세 가지로 본다.

## 2. 알고리즘별 유효성 정리 [필수]

### 2-1. C-Rank — 블로그(출처) 단위 신뢰도 → **여전히 유효, 오히려 더 중요**
- "누가 썼는가"를 평가한다. 한 주제를 오래, 꾸준히, 전문적으로 다룬 블로그에 점수를 준다.
- AI 브리핑 인용 선정에도 C-Rank가 주요 입력값으로 작용한다는 분석이 있다.
- 평가 요소: **주제 일관성, 콘텐츠 누적량, 활동성(최근 발행), 소통(진짜 댓글·공감)**
- 지수가 높아도 최근 30일간 발행이 없으면 노출이 크게 줄어든다는 관찰이 많다.

### 2-2. D.I.A / D.I.A+ — 문서 단위 품질 → **유효**
- "이 글이 좋은가"를 평가한다. 경험·정보의 충실도, 독창성, 사용자 반응을 본다.
- 핵심 지표: **체류 시간**(업계 관찰상 최소 1분 30초~2분 30초 이상), 이미지 원본성, 제목-본문 일관성
- 원본 이미지 여부를 판별하는 기술이 있다고 알려져 있다.

### 2-3. AI 브리핑 — 인용 선정 → **2026년 최대 변수**
- 선호 구조: **두괄식 답변 + 질문형 소제목 + 리스트/표 + 경험 근거 + 명확한 출처**
- 정보성 질의일수록 낮은 순위에서도 인용 기회가 열려 있다.

## 3. 키워드 선정 [필수]

1. **메인 키워드 1개만 정한다.** 한 글에 메인 키워드 여러 개를 섞지 않는다.
2. **롱테일(세부) 키워드를 우선한다.**
   - ❌ "제주도 여행" → ✅ "아이와 가기 좋은 제주 서쪽 코스"
   - 신규·저지수 블로그는 월간 검색량 약 100~500 수준의 세부 키워드부터 공략한다.
3. **검색 의도를 문장으로 정의한다.** 예: "검색자는 ○○를 처음 해보려는 사람이고, ○○ 방법과 주의점을 알고 싶다."
4. **실제 검색어를 근거로 한다.** 네이버 자동완성, 지식iN 질문, 스마트블록 주제를 참고한다.
5. **질문형 키워드도 고려한다.** AI 브리핑 시대에는 "○○ 어떻게 하나요?", "○○ 갑자기 떨어진 이유는?" 같은 질문형 검색이 늘었다.
6. **띄어쓰기는 실제 검색어와 동일하게.** "블로그 상위노출"처럼 자연스럽게 쓰고, 단어를 인위적으로 쪼개지 않는다.

## 4. 제목 작성 규칙 [필수]

| 항목 | 규칙 |
| :--- | :--- |
| **키워드 위치** | 핵심 키워드를 **제목 앞쪽**에 배치 |
| **키워드 횟수** | **1회만**. 반복하면 역효과 |
| **길이** | 약 **25~35자** 권장 (모바일 검색결과에서 약 35자 전후까지 표시) |
| **구체성** | 숫자, 대상, 상황을 넣는다 ("5가지", "초보자용", "3분 만에") |
| **검색 의도 일치** | 제목이 약속한 내용을 본문이 반드시 다룬다 (제목-본문 일관성) |
| **상황·고민형** | 검색자의 구체적 상황을 담은 제목이 AI 브리핑·인기글에 잘 잡힌다 |

**좋은 예**
- "클로드 코드 핵심 기능 5가지, 초보자가 먼저 써봐야 할 것"
- "아이패드 필기용 구매 전 확인할 3가지, 직접 써보고 후회한 점"

**나쁜 예**
- "클로드 코드 클로드코드 기능 클로드 코드 사용법" (키워드 반복)
- "요즘 핫한 그것! 꼭 보세요!!" (키워드 없음, 낚시성)

## 5. 본문 구조 [필수]

### 5-1. 분량
- **1,500자 이상** 권장 (공백 제외 기준으로 넉넉히). 단, 분량을 채우려 늘리는 것보다 **질문에 완결된 답**을 주는 게 우선이다.
- 다룰 세부 질문이 너무 많아지면 억지로 늘리지 말고 **글을 나눈다.**

### 5-2. 권장 뼈대

```
제목 (H1 역할, 1개)

[첫 문단 — 3줄 두괄식]
1줄: 결론(핵심 답)
2줄: 조건/근거
3줄: 이 글에서 다룰 내용

[목차] (긴 글일 때)

## 소제목 1 (질문형 권장, 관련 키워드 포함)
  ### 하위 소제목 (필요 시)
  본문 300~500자 + 리스트/표
  [이미지]

## 소제목 2 ...
## 소제목 3 ...
(대제목은 3~5개)

## 자주 묻는 질문 (선택, AI 인용에 유리)

## N. 마무리 (핵심 요약 + 메인 키워드 1회 재언급. 소제목 이름은 스타일 가이드 0장)
```

### 5-3. 가독성 규칙
- 문단 나누기는 **스타일 가이드 4장('문단' 규칙)**을 따른다.
- 소제목은 **질문형**("○○는 왜 필요할까?")을 적극 쓴다. AI가 질문-답 쌍으로 추출하기 쉽다.
- 비교는 **표**, 절차는 **번호 목록**, 요점은 **불릿 목록**으로 정리한다.
- 중간중간 독자에게 질문을 던져 스크롤을 유도한다.

### 5-4. 신뢰도 장치 (2026년 핵심)
- **구체적 경험**: 날짜, 금액, 과정, 시행착오를 쓴다.
- **공식 출처 링크**: 정부·기관·공식 문서 링크로 근거를 밝힌다.
- **정보성 80% : 홍보성 20%** 이하로 유지한다.

## 6. 키워드 개수와 배치 [필수]

| 위치 | 메인 키워드 | 비고 |
| :--- | :--- | :--- |
| 제목 | **1회** (앞쪽) | 필수 |
| 첫 문단(첫 100자 이내) | **1회** | 필수 |
| 소제목(H2/H3) | 메인 또는 **연관 키워드** 2~3곳 | 같은 단어만 반복하지 말 것 |
| 본문 | 자연스럽게 **총 3~5회** 수준 | 동의어·관련어로 분산 |
| 마무리 | **1회** 재언급 | 권장 |

- 업계에서 말하는 키워드 밀도는 대략 **1.5~3%** 수준이다. 이 범위를 넘기면 반복으로 판단될 위험이 있다.
- **동의어·연관어를 함께** 쓴다. (예: "상위노출" ↔ "검색 노출", "상위 랭크")
- 2026년에는 "키워드를 몇 번 넣었나"보다 "검색 의도를 얼마나 정확히 풀었나"가 훨씬 중요하다. 횟수를 맞추려고 문장을 비틀지 않는다.

## 7. 이미지 규칙 [필수]

| 항목 | 규칙 |
| :--- | :--- |
| **개수** | 정보형 **5~10장** 권장 (최소 3장). 후기·리뷰형은 더 많아도 무방 |
| **배치** | 소제목마다 1장 이상, 또는 **3~5문단마다 1장**. 한곳에 몰지 않는다 |
| **원본성** | 직접 촬영·직접 제작 이미지 우선. 다른 블로그 사진 재사용 금지 |
| **대표 이미지(썸네일)** | 첫 이미지 또는 지정 이미지. 정방형 비율이 검색결과에서 잘 보인다 |
| **설명(ALT/캡션)** | 이미지 설명에 관련 키워드를 자연스럽게 1회 정도 |
| **용량** | 너무 무거운 GIF·대용량 이미지는 로딩을 늦추므로 피한다 |
| **동영상** | 짧은 영상(15초 이상)은 체류 시간 증가에 도움이 된다 [선택] |

**글쓰기 에이전트 표기 규칙**: 이미지가 들어갈 자리에 아래 마커를 넣는다.
```
[IMAGE: 썸네일 | 설명: ...]
[IMAGE: 비교표 | 설명: ...]
[IMAGE: 다이어그램 | 설명: ...]
[IMAGE: 포인트카드 | 설명: ...]
```

## 8. 해시태그(태그) 활용법 [권장]

- **개수: 5~10개**가 안전 범위. 관련성 높은 3~5개만으로도 충분하다. 30개를 꽉 채우지 않는다.
- **구성**: 메인 키워드 1 + 세부(롱테일) 키워드 2~4 + 연관 주제어 2~4
- **네이버 태그는 띄어쓰기를 쓸 수 없다.** 붙여 쓴다. (예: `#클로드코드`, `#블로그자동화`)
- **본문과 무관한 태그 금지.** 유행어·인기 태그를 관련 없이 붙이면 오히려 불리하다.
- 태그가 검색 순위에 미치는 영향은 **본문과 이미지보다 작다**는 것이 업계 공통 견해다. 태그는 주제 분류와 내부 탐색 보조 수단으로 본다.
- 본문 문장 속에 `#`을 남발하지 않는다. 태그는 글 하단 태그 입력란에 넣는다.

**예시** (주제: 클로드 코드 핵심 기능)
`#클로드코드 #ClaudeCode #클로드코드사용법 #AI코딩도구 #바이브코딩 #AI에이전트`

## 9. 블로그 운영 규칙 (지수 관리) [권장]

- **주제 일관성**: 한 블로그(또는 한 카테고리)는 한 분야에 집중한다. 잡다한 주제는 전문성 점수를 분산시킨다.
- **꾸준한 발행**: 몰아서 쓰기보다 **주 3~5회** 일정한 주기. 최근 30일 활동성이 중요하다.
- **누적량**: 한 카테고리에 글이 충분히(업계 관찰상 수십 개 이상) 쌓여야 전문성이 인정된다.
- **진짜 소통**: 복사 댓글이 아닌 실제 대화.
- **프로필 정비**: 블로그 소개에 분야·경력·전문성을 명시한다.
- **발행 후 점검**: 발행 뒤 약 7일 안에 노출 여부를 보고, 고칠 때는 **제목과 첫 문단만** 조정한다.

## 10. 하지 말아야 할 행동 [필수]

| 금지 행동 | 이유 |
| :--- | :--- |
| 제목·본문에 키워드 과도 반복 | 스팸 신호, 순위 하락 |
| 다른 글 복사·붙여넣기, 짜깁기 | 유사문서 판정은 2026년에도 가장 강력한 저품질 원인 |
| AI 생성 글을 다듬지 않고 그대로 발행 | 네이버가 LLM 기반으로 AI 양산형 글을 걸러낸다고 발표 |
| 짧은 글 대량 발행 | 저품질 콘텐츠 대량 발행은 대표적 저품질 원인 |
| 발행한 글 대량 삭제·비공개 전환 | 블로그 전체 품질 지수 하락의 주요 원인으로 지목됨 |
| 제목과 본문 동시 대폭 수정, 대량 재발행 | 문서 평가가 리셋되거나 불안정해질 수 있음 |
| 본문과 무관한 해시태그 남발 | 관련성 신호 훼손 |
| 경쟁 플랫폼(유튜브 등) 외부 링크 과다 | 네이버 밖 이탈 유도로 불리하다는 관찰이 많음 (공식 확인은 아님) |
| 금칙어·과장 표현("100% 보장", "무조건") | 신뢰도 하락, 일부 단어는 노출 제한 |
| 홍보·협찬 글 비중 과다 | 체험·광고성 글은 전체의 30% 이하 권장 |
| 경험 없는 후기 작성 | 2026년 필터링 강화 대상 |

## 11. 발행 전 체크리스트

**키워드·제목**
- [ ] 메인 키워드 1개, 세부(롱테일) 키워드인가?
- [ ] 제목 앞쪽에 메인 키워드가 1회 있는가? 길이는 25~35자인가?
- [ ] 제목이 약속한 내용을 본문이 모두 다루는가?

**본문**
- [ ] 첫 문단 3줄 안에 결론이 있는가? (두괄식)
- [ ] 첫 100자 안에 메인 키워드가 있는가?
- [ ] 대제목 3~5개, 질문형 소제목이 있는가?
- [ ] 리스트·표로 정리된 부분이 있는가?
- [ ] 1,500자 이상이며, 키워드가 자연스럽게 3~5회인가?
- [ ] 직접 경험(날짜·과정·수치)과 공식 출처 링크가 있는가?
- [ ] 문단이 스타일 가이드 4장 규칙(2~3문장 덩어리, 문단 사이 빈 줄)을 따르는가?

**이미지·태그**
- [ ] 원본 이미지 5장 이상이 고르게 배치됐는가?
- [ ] 이미지 마커에 종류와 설명이 적혀 있는가?
- [ ] 태그 5~10개, 띄어쓰기 없이, 본문과 관련 있는가?

**금지 행동**
- [ ] 키워드 반복·복붙·과장 표현이 없는가?
- [ ] AI가 쓴 티(뻔한 일반론, 근거 없는 나열)가 남아 있지 않은가?
