# CLAUDE.md

이 폴더는 "동탄 중심 부동산 시장 모니터링 시스템"이다. 기준 문서는 `PRD.md`이며, 요구사항이 바뀌면 PRD부터 고친다. 개발자는 코딩 비전공자이므로 설명은 한국어로, 결론 먼저, 전문 용어는 문단 끝 각주로 쓴다.

## 작업 규칙

- 한 세션에 PRD 11절 로드맵의 한 단계만 진행하고, 완료 기준을 통과하면 Git에 저장한다.
- 월 0원: 유료 API·서비스 금지. 대안이 없으면 먼저 사용자에게 묻는다.
- 비밀 값(공공데이터포털 인증키, Gmail 앱 비밀번호)은 `.env`에만 둔다. 코드·로그·커밋·화면 출력에 노출하지 않고, `.env`를 읽거나 출력하지 않는다.
- 코드에 지역 이름·지역코드·기준값을 직접 쓰지 않는다. 지역은 `config/regions.yaml`, 기준값은 `config/settings.yaml`에서만 읽는다.
- 원본 지역코드와 원본 거래는 바꾸지 않는다. 분석용 "분석구역"을 따로 둔다.
- 판정은 "거래 데이터가 보여주는 신호"로 표기하고, 표본이 `min_sample` 미만이면 방향 판정 대신 "판단 보류"로 낸다.
- Claude 사용량 절약: 원본 데이터를 통째로 읽지 말고 월별·지역별 건수 요약표로 확인한다.
- 코드는 역할별 파일로 나눈다(`src/`: 수집, 저장, 분석, 대시보드, 보고서, 실행).

## 폴더

- `config/`: 지역·기준값 설정 / `data/`: SQLite 파일(Git 제외) / `logs/`: 실행 로그(Git 제외) / `src/`: 코드

## 환경

- 대상 PC는 Windows. Python 가상환경은 `python -m venv .venv`, 활성화는 `.venv\Scripts\activate`, 설치는 `pip install -r requirements.txt`.
- 인증키는 `.env.example`을 `.env`로 복사해 채운다.
